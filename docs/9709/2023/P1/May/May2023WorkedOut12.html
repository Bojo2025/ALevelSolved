Question 1 [3]

The equation of a curve is such that dy/dx = 4/(x − 3)³ for x > 3. The curve passes through the point (4, 5). Find the equation of the curve.

Original paper page 2
y = ∫4(x − 3)⁻³ dx = −2(x − 3)⁻² + C At (4, 5): 5 = −2 + C → C = 7

y = 7 − 2/(x − 3)²

Question 2 [4]

The coefficient of x⁴ in the expansion of (x + a)⁶ is p, and the coefficient of x² in the expansion of (ax + 3)⁴ is q. It is given that p + q = 276. Find the possible values of the constant a.

p = C(6,4)a² = 15a² q = C(4,2)(a)²(3)² = 54a² 15a² + 54a² = 276 → 69a² = 276 → a² = 4

Question 4 [3]

Solve the equation 8x⁶ + 215x³ − 27 = 0.

Original paper page 5
Let y = x³: 8y² + 215y − 27 = 0 (8y − 1)(y + 27) = 0 → y = 1/8 or y = −27 x³ = 1/8 → x = 1/2; x³ = −27 → x = −3

x = 1/2 or x = −3 (real roots)

Question 7 [3 + 2 + 2 + 3 + 3]

(a)(i) By expanding (cos θ + sin θ)², find the three solutions of (cos θ + sin θ)² = 1 for 0 ≤ θ ≤ π. (ii) Hence verify that the only solutions of cos θ + sin θ = 1 for 0 ≤ θ ≤ π are 0 and ½π. (b) Prove the identity sin θ/(cos θ + sin θ) + (1 − cos θ)/(cos θ − sin θ) = (cos θ + sin θ − 1)/(1 − 2 sin² θ). (c) Using the results of (a)(ii) and (b), solve sin θ/(cos θ + sin θ) + (1 − cos θ)/(cos θ − sin θ) = 2(cos θ + sin θ − 1) for 0 ≤ θ ≤ π.

Original paper page 8

(a)(i) [3]

(cos θ + sin θ)² = 1 + sin 2θ = 1 → sin 2θ = 0 2θ = 0, π, 2π → θ = 0, ½π, π

θ = 0, ½π, π

(a)(ii) [2]

θ = π gives cos π + sin π = −1 ≠ 1, so it is rejected. θ = 0 gives 1 and θ = ½π gives 1, so these are the only solutions.

Verified: θ = 0 or ½π

Original paper page 9

(b) [3]

Common denominator (cos θ + sin θ)(cos θ − sin θ) = cos 2θ = 1 − 2 sin² θ Numerator: sin θ(cos θ − sin θ) + (1 − cos θ)(cos θ + sin θ) = sin θ cos θ − sin² θ + cos θ + sin θ − cos² θ − sin θ cos θ = cos θ + sin θ − 1

Identity shown

(c) [3]

Using (b): (cos θ + sin θ − 1)/(1 − 2 sin² θ) = 2(cos θ + sin θ − 1) So (cos θ + sin θ − 1)[1/(1 − 2 sin² θ) − 2] = 0 Case 1: cos θ + sin θ − 1 = 0 → θ = 0 or ½π (from (a)(ii)) Case 2: 1/(1 − 2 sin² θ) = 2 → 1 − 2 sin² θ = ½ → sin θ = ½ → θ = π/6, 5π/6 Denominators are non-zero at all four values.

θ = 0, π/6, ½π, 5π/6

Question 8 [2 + 2 + 2 + 2 + 6]

f(x) = 3 + 2 sin(¼x) for 0 ≤ x ≤ 2π. (a) Sketch the graph of y = f⁻¹(x). (b) Find an expression for f⁻¹(x). (c) Complete the sketch of g(x) = 3 + 2 sin(¼x) for −2π ≤ x ≤ 2π and explain whether g has an inverse. (d) Describe three transformations that take y = sin x (0 ≤ x ≤ ½π) to y = f(x), in order.

Original paper page 10

(a) [2]

f runs from (0, 3) to (2π, 5). Reflect in y = x: the inverse runs from (3, 0) to (5, 2π). It is a reflection of the given curve in the line y = x.

Reflect the curve in y = x (from (3, 0) to (5, 2π))

(b) [2]

y = 3 + 2 sin(¼x) → sin(¼x) = (y − 3)/2 → x = 4 arcsin((y − 3)/2)

f⁻¹(x) = 4 arcsin((x − 3)/2), for 3 ≤ x ≤ 5

Original paper page 11

(c) [2]

For −2π ≤ x ≤ 2π, x/4 lies in [−½π, ½π], where sin is strictly increasing. So g is one-to-one, and the curve runs from (−2π, 1) to (2π, 5).

g has an inverse (it is one-to-one on this domain)

(d) [6]

1. Stretch parallel to the x-axis with scale factor 4 (sin x → sin(x/4)), which maps 0 ≤ x ≤ ½π to 0 ≤ x ≤ 2π. 2. Stretch parallel to the y-axis with scale factor 2 (→ 2 sin(x/4)). 3. Translate by 3 units in the positive y-direction (→ 3 + 2 sin(x/4)). The order matters: the x-stretch is applied first.

x-stretch ×4, then y-stretch ×2, then translation (0, 3)

a = 20 or a = 80

Question 10 [5 + 4 + 4]

The circle (x − a)² + (y − 3)² = 20 has the line y = ½x + 6 as a tangent at P. (a) Show that one value of a is 4 and find the other value. (b) For a = 4, find the normal to the circle at P. (c) For a = 4, find the two tangents to the circle parallel to the normal in (b).

Original paper page 14

(a) [5]

Line: x − 2y + 12 = 0. Centre (a, 3), radius √20. Distance: |a − 6 + 12|/√5 = √20 → |a + 6| = 10 a = 4 (given) or a = −16

Other value: a = −16

Original paper page 15

(b) [4]

Normal through the centre (4, 3) perpendicular to the tangent (slope −2): y = −2(x − 4) + 3 Meets the tangent y = ½x + 6 where −2x + 11 = ½x + 6 → x = 2, y = 7 P = (2, 7); normal slope = (3 − 7)/(4 − 2) = −2

y = −2x + 11, i.e. 2x + y − 11 = 0

(c) [4]

Tangents parallel to the normal have the form 2x + y − c = 0. Distance from (4, 3): |11 − c|/√5 = √20 → |11 − c| = 10 → c = 1 or 21

y = −2x + 1 and y = −2x + 21
