Question 2 [5]

Original paper page 3

The solutions of |4x − 1| = |x + 3| are x = p and x = q, where p < q. Find the exact values of p and q, and hence the exact value of |p − 2| − |q − 1|.

Square both sides: 16x² − 8x + 1 = x² + 6x + 9 → 15x² − 14x − 8 = 0 (3x − 4)(5x + 2) = 0 p = −2/5, q = 4/3 |p − 2| − |q − 1| = 12/5 − 1/3 = 31/15

p = −2/5, q = 4/3, value = 31/15

Question 3 [5]

Original paper page 4

y = Axᵏ. The graph of ln y against ln x passes through (0.56, 2.87) and (0.81, 3.47). Find k and A correct to 2 s.f.

ln y = k ln x + ln A k = (3.47 − 2.87)/(0.81 − 0.56) = 0.60/0.25 = 2.4 ln A = 2.87 − 2.4(0.56) = 1.526 → A = e^1.526 = 4.6

k = 2.4, A = 4.6

p(−1/2) = −a/8 + 23/4 + a/2 − 8 = 0 → 3a/8 = 9/4 → a = 6 p(x) = 6x³ + 23x² − 6x − 8 = (2x + 1)(3x² + 10x − 8) = (2x + 1)(3x − 2)(x + 4)

a = 6, p(x) = (2x + 1)(3x − 2)(x + 4)

x = 3cos2θ, y = 4sinθ for π ≤ θ ≤ 3π/2. Gradient at P is 2. Find θ at P to 3 s.f.

dx/dθ = −6sin2θ = −12sinθcosθ, dy/dθ = 4cosθ dy/dx = −1/(3sinθ) = 2 → sinθ = −1/6 θ = π + arcsin(1/6) = 3.31 rad

Original paper page 11

The line 3x + y = 0 meets the curve at Q. Find the gradient of the curve at Q to 3 s.f.

y = −3x: 4sinθ = −9cos2θ = −9 + 18sin²θ 18sin²θ − 4sinθ − 9 = 0 → sinθ = (4 − √664)/36 = −0.60467 (root in range) Gradient = −1/(3sinθ) = −1/(3 × −0.60467) = 0.551

Gradient at Q = 0.551
