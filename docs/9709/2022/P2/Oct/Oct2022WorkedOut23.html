Question 1 [4]

Original paper page 3

Solve the inequality |2x − 5| > x.

Square: (2x − 5)² > x² → 3x² − 20x + 25 > 0 → (3x − 5)(x − 5) > 0 So x < 5/3 or x > 5 (all x < 0 also satisfy the inequality since x is negative)

x < 5/3 or x > 5

(a) [3] p(x) = 12x³ − 9x² + 8x − 4. Find the quotient when divided by (4x − 3) and show the remainder is 2.

12x³ − 9x² + 8x − 4 = (4x − 3)(3x² + 2) + 2

Quotient 3x² + 2, remainder 2

(b) [6] Hence find ∫₂¹² (p(x)/(4x − 3) − 3x²) dx in the form a + ln b.

p(x)/(4x − 3) − 3x² = 2 + 2/(4x − 3) ∫ = [2x + (1/2)ln(4x − 3)]₂¹² = (24 + ½ln45) − (4 + ½ln5) = 20 + ½ln9 = 20 + ln3

a = 20, b = 3
