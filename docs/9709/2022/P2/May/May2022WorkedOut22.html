Question 1 [3]

Original paper page 2

Given y = (ln x)/x², find the exact value of dy/dx when x = e.

dy/dx = (x − 2x ln x)/x⁴ = (1 − 2ln x)/x³ At x = e: (1 − 2)/e³ = −1/e³

dy/dx = −1/e³

Question 3 [5]

Original paper page 4

The curve e²ˣcos2y + sin y = 1. Find the exact gradient at (0, π/6).

Differentiate: 2e²ˣcos2y − 2e²ˣsin2y · dy/dx + cos y · dy/dx = 0 At (0, π/6): 2(1/2) − 2(√3/2)dy/dx + (√3/2)dy/dx = 0 1 = (√3/2) dy/dx → dy/dx = 2/√3

Gradient = 2/√3 = 2√3/3

(a) [4] Use the trapezium rule with three intervals to show ∫₁⁴ ln x dx ≈ ln 12.

h = 1, y-values: ln1, ln2, ln3, ln4 Area ≈ ½[ln1 + 2ln2 + 2ln3 + ln4] = ln2 + ln3 + ln2 = ln 12

≈ ln 12

(b) [2] Use a graph of y = ln x to show that ln 12 is an under-estimate.

The curve y = ln x is concave down, so each trapezium's top chord lies below the curve. The trapezium estimate is therefore less than the true value.

ln 12 is an under-estimate.

Question 7 [8]

Original paper page 10

The curves y = √(2π − 2x) and y = sin²x for 0 ≤ x ≤ π. The shaded region is bounded by the two curves and x = 0. Find the exact area.

Area = ∫₀^π [√(2π − 2x) − sin²x] dx ∫₀^π √(2π − 2x) dx = (1/3)(2π)^(3/2) (substitute u = 2π − 2x) ∫₀^π sin²x dx = ∫₀^π ½(1 − cos2x) dx = π/2 Area = (1/3)(2π)^(3/2) − π/2

Area = (2π)^(3/2)/3 − π/2 ≈ 3.68
