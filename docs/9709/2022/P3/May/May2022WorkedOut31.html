(a) [4] The curve x³ + y³ + 2xy + 8 = 0. Express dy/dx in terms of x and y.

3x² + 3y² dy/dx + 2y + 2x dy/dx = 0 dy/dx = −(3x² + 2y)/(3y² + 2x)

Original paper page 15

(b) [5] The tangents at x = 0 and at y = 0 intersect at acute angle θ. Find the exact tan θ.

x = 0: y³ = −8 → y = −2, gradient m₁ = −(2y)/(3y²) = −(−4)/12 = 1/3 y = 0: x³ = −8 → x = −2, gradient m₂ = −(3x²)/(2x) = −12/(−4) = 3 tanθ = |(m₂ − m₁)/(1 + m₁m₂)| = |(3 − 1/3)/2|

tan θ = 4/3
