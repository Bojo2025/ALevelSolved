(a) [5] f(x) = 4cos⁴x + cos²x − k for 0 ≤ x ≤ 2π, k = 3. Solve f(x) = 0 exactly.

Let u = cos²x: 4u² + u − 3 = 0 → (4u − 3)(u + 1) = 0 u = −1 is rejected (u ≥ 0), so cos²x = ¾, cos x = ±√3/2

(b) [5] Use the quadratic formula to show that, when k > 5, f(x) = 0 has no solutions.

u = (−1 ± √(1 + 16k))/8 For k > 5: √(1 + 16k) > 9, so u₊ > 1 (impossible, since u = cos²x ≤ 1) u₋ < 0 (impossible, since u ≥ 0)

No solutions when k > 5
