(a) [3] Points A(5, 2) and B(10, −1). Find the equation of the perpendicular bisector of AB.

Midpoint = (15/2, 1/2) Gradient AB = (−1 − 2)/(10 − 5) = −3/5, so perpendicular gradient = 5/3 y − 1/2 = 5/3 (x − 15/2) → 3y = 5x − 36

Question 2 [5]

Original paper page 4

The first, second and third terms of an arithmetic progression are a, 2a and a² (a > 0). Find the sum of the first 50 terms.

Common difference: 2a − a = a² − 2a → a² − 3a = 0 → a = 3 (a > 0) d = 3, so the terms are 3, 6, 9, … S₅₀ = 50/2 × (2(3) + 49(3)) = 25 × 153

S₅₀ = 3825

Question 7 [3 + 4]

Original paper page 10

(a) [3] Prove that (sinθ/(sinθ + cosθ)) + (cosθ/(sinθ − cosθ)) = (tan²θ + 1)/(tan²θ − 1).

LHS = [sinθ(sinθ − cosθ) + cosθ(sinθ + cosθ)] / (sin²θ − cos²θ) = (sin²θ + cos²θ) / (sin²θ − cos²θ) Divide top and bottom by cos²θ: = (tan²θ + 1)/(tan²θ − 1)

Identity proved.

Original paper page 11

(b) [4] Hence find the exact solutions of the equation in (a) equal to 2 for 0 ≤ θ ≤ π.

(tan²θ + 1) = 2(tan²θ − 1) → tan²θ = 3 → tanθ = ±√3 In 0 ≤ θ ≤ π: θ = π/3 or θ = 2π/3

θ = π/3, 2π/3
