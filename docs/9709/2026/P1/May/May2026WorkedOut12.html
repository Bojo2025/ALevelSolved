Question 1 [3]

Solve the equation 3x² − 8 − 16/x² = 0.

Original paper page 2
Multiply by x²: 3x⁴ − 8x² − 16 = 0 (3x² + 4)(x² − 4) = 0 3x² + 4 > 0, so x² = 4

x = 2 or x = −2

Question 2 [5 + 2]

The graph of y = f(x) is shown with solid lines and the graph of y = g(x) with broken lines. (a) Describe fully a sequence of transformations that transforms y = f(x) to y = g(x), in order. (b) Find g(x) in the form af(x + b) + c.

Original paper page 2

(a) [5]

Reading the graphs: f has points (0, −10), (2, −4), (4, −6), (6, −6). g has points (1, 0), (3, 3), (5, 2), (7, 2). Translate f by 1 unit in the positive x-direction: f(x − 1). Stretch parallel to the y-axis with scale factor ½: ½f(x − 1). Translate by 5 units in the positive y-direction: ½f(x − 1) + 5. Check: at x = 3, ½f(2) + 5 = −2 + 5 = 3 ✓; at x = 5, ½f(4) + 5 = 2 ✓.

Translate by 1 in the +x direction, then stretch in the y-direction by scale factor ½, then translate by 5 in the +y direction

(b) [2]

g(x) = ½f(x − 1) + 5 = ½f(x + (−1)) + 5

a = ½, b = −1, c = 5

Question 3 [6]

The perpendicular bisector of the line joining (4, 3) and (−2, 6) meets the line x − 4y − 4 = 0 at P. Find the coordinates of P.

Original paper page 2
Midpoint: (1, 4.5). Segment slope: (6 − 3)/(−2 − 4) = −½ Bisector slope: 2, so y − 4.5 = 2(x − 1) → y = 2x + 2.5 Substitute into x − 4y − 4 = 0: x − 8x − 10 − 4 = 0 → x = −2, y = −1.5 Check: −2 + 6 − 4 = 0 ✓

P = (−2, −1.5)

Question 4 [2 + 1 + 4]

(a)(i) Find the first three terms, in ascending powers of x, in the expansion of (3 − ½x)⁴. (ii) Find the first three terms, in ascending powers of x, in the expansion of (2 + ax)³. (b) The coefficient of x² in (3 − ½x)⁴(2 + ax)³ is −108. Find a.

Original paper page 2

(a)(i) [2]

(3 − ½x)⁴ = 81 + 4(27)(−½x) + 6(9)(¼x²) + … = 81 − 54x + (27/2)x² + …

81 − 54x + (27/2)x²

(a)(ii) [1]

(2 + ax)³ = 8 + 3(4)(ax) + 3(2)(ax)² + … = 8 + 12ax + 6a²x² + …

8 + 12ax + 6a²x²

(b) [4]

Coefficient of x²: 81 · 6a² + (−54)(12a) + (27/2)(8) = 486a² − 648a + 108 = −108 486a² − 648a + 216 = 0 → 9a² − 12a + 4 = 0 → (3a − 2)² = 0

a = 2/3

Question 5 [7]

d²y/dx² = 6x² + p, where p is a constant. The curve has minimum points at (2, 3) and (−2, 3). Find the coordinates of the other stationary point.

Original paper page 3
dy/dx = 2x³ + px + A Stationary at x = 2 and x = −2: 16 + 2p + A = 0 and −16 − 2p + A = 0 So A = 0 and p = −8, giving dy/dx = 2x(x² − 4) Stationary points at x = 0, ±2. y = ½x⁴ − 4x² + B. At (2, 3): 8 − 16 + B = 3 → B = 11 At x = 0: y = 11. d²y/dx² = −8 < 0, so this is a maximum.

(0, 11)

Question 6 [4]

Solve cos⁻¹(sin²x + (3/2) sin x) = (2/3)π for 0 ≤ x ≤ 2π.

Original paper page 3
cos(2π/3) = −½, so sin²x + (3/2) sin x = −½ Let s = sin x: 2s² + 3s + 1 = 0 → (2s + 1)(s + 1) = 0 s = −½ or s = −1 sin x = −½: x = 7π/6 or 11π/6 sin x = −1: x = 3π/2

x = 7π/6, 3π/2, 11π/6

Question 7 [4 + 3 + 3]

Original paper page 3

a + d = 60, a + 3d = 52 → d = −4, a = 64 Last term: 64 − 4(n − 1) = −28 → n = 24 Sum = 12(64 + (−28)) = 432

432

(k + 4)/9 = k²/(k + 4) → (k + 4)² = 9k² k + 4 = 3k gives k = 2 (rejected, k negative) k + 4 = −3k gives k = −1

k = −1

Terms 9, 3, 1: r = ⅓, a = 27 S∞ = 27/(1 − ⅓) = 81/2

S∞ = 81/2 (40.5)

Question 8 [4 + 7]

A diameter of a circle has end-points (−2, 4) and (8, 8). (a) Find an equation of the circle. (b) The line y = x + 6 meets the circle at P and Q. Find the exact distance PQ in the form a√b.

Original paper page 3

Centre: midpoint (3, 6). Radius²: (10² + 4²)/4 = 29 (x − 3)² + (y − 6)² = 29

(x − 3)² + (y − 6)² = 29

(b) [7]

Substitute y = x + 6: (x − 3)² + x² = 29 → x² − 3x − 10 = 0 (x − 5)(x + 2) = 0 → x = 5 or x = −2 P, Q = (5, 11) and (−2, 4) PQ = √(7² + 7²) = √98 = 7√2

PQ = 7√2

Question 9 [4 + 7]

The curve y = 3√(2x + 1) and the normal to the curve at R(4, 9), with the line y = a (a > 0). (a) Find the area of the shaded region. (b) Find the exact value of a for which the triangle enclosed by the y-axis, the normal at R and the line y = a has area equal to the area in (a).

Original paper page 4

(a) [4]

Area = ∫₀⁴ 3(2x + 1)^(1/2) dx = [(2x + 1)^(3/2)]₀⁴ = 27 − 1 = 26

26

(b) [7]

dy/dx = 3/√(2x + 1) = 1 at x = 4, so the normal has gradient −1. Normal: y − 9 = −(x − 4) → y = 13 − x, which meets the y-axis at (0, 13). Line y = a meets the normal at x = 13 − a. Triangle area = ½(13 − a)² = 26 → (13 − a)² = 52 → a = 13 − 2√13 (≈ 5.79)

a = 13 − 2√13

Question 10 [3 + 2 + 4]

f(x) = px² − 2x + p + 4 for x ∈ ℝ. (a) Find the exact values of p for which f(x) = 0 has repeated roots. g(x) = px² − 2x + p + 4 for x ≥ a, with p, a > 0. (b)(i) Show that the least a for which g⁻¹ exists is 1/p. (ii) Given p = 2 and g⁻¹ exists, find g⁻¹(x).

Original paper page 4

(a) [3]

Discriminant: 4 − 4p(p + 4) = 0 → p² + 4p − 1 = 0

p = −2 ± √5

(b)(i) [2]

g has its turning point at x = 1/p. g is increasing for x ≥ 1/p, so g⁻¹ exists only when a ≥ 1/p.

Least a = 1/p

(b)(ii) [4]

g(x) = 2x² − 2x + 6 = 2(x − ½)² + 11/2, for x ≥ ½ y = 2(x − ½)² + 11/2 → x = ½ + √((y − 11/2)/2) = ½ + ½√(2y − 11)

g⁻¹(x) = ½ + ½√(2x − 11), for x ≥ 11/2
